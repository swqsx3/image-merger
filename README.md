# 图片合成工作台

批量把「主图」居中叠加到「背景图」上的纯前端工具。所有处理都在浏览器本地完成，图片不会上传到任何服务器。

## 在线使用

打开 `index.html` 即可（双击本地文件，或起个静态服务：`python -m http.server`）。无需构建、无需依赖安装。

## 功能

- **批量合成**：一次上传几十上百张主图，配合背景图批量产出
- **主图居中**：主图严格居中放置在背景图正中央，可加偏移微调
- **三种配对**：单背景 × 全部主图 / 一一对应 / 交叉全组合
- **尺寸自定义**
  - 画布尺寸：跟随背景、跟随主图，或任意自定义宽高；内置 1080²、3:4、9:16、16:9 等预设；支持锁定宽高比、一键取背景图真实尺寸
  - 主图尺寸：按画布比例、固定宽度、自定义宽高（可锁定原图比例或自由拉伸）、原始尺寸、铺满画布
- **外观微调**：不透明度、圆角、投影、水平/垂直偏移
- **导出**：PNG / JPG / WebP + 质量调节；可单张下载或打包 ZIP（自研 store 模式打包，无第三方依赖）

## 使用步骤

1. 上传**背景图**（底层大图）
2. 批量上传**主图**（要居中叠加的那批图）
3. 选择配对方式，在右侧实时预览中调参数
4. 点「批量合成」，然后打包下载 ZIP

## 目录结构

```
index.html   页面结构
styles.css   样式（三栏紧凑布局、预览区 sticky 常驻）
app.js       核心逻辑：上传、合成、ZIP 打包
```

## 实现要点

- 合成基于 Canvas 2D：画布尺寸 → 绘制背景（cover / contain / stretch / original）→ 计算主图尺寸 → 居中绘制
- 居中公式：`dx = (画布宽 - 主图宽) / 2 + 水平偏移`，纵向同理
- 圆角与投影走离屏 Canvas，避免 `clip()` 把投影裁掉
- ZIP 导出为纯前端实现（CRC32 + 本地文件头 + 中央目录，store 模式），不依赖 JSZip/CDN
- `window.__IMGMerge__` 暴露 `compose / buildZip / crc32` 等，方便自动化测试

## 兼容性

需要支持 Canvas `toBlob` 的现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本）。
